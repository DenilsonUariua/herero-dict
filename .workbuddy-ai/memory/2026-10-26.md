# 2026-10-26

## RAG translation + bidirectional dictionary

- Added `/translate` page (sentence mode via RAG, word mode offline) with settings dialog.
- New RAG engine in `src/lib/rag/`: hybrid BM25/fuzzy/stem retriever, Otjiherero grammar prompt, OpenAI-compatible provider (server proxy preferred, browser BYOK fallback), localStorage result cache.
- Retrieval design decision: lexical BM25 chosen over embeddings — corpus is tiny (~116 entries), query is a full sentence, so content-word recall beats topical similarity; retriever is a pure function so a dense index can replace it later.
- Lexicon pipeline: `scripts/lib/lexicon-parse.mjs` + `scripts/build-lexicon.mjs` → `public/lexicon.json` (committed; `words.json` is gitignored). Parser handles OCR damage (`o20-1`, `WO0`) and flags suspect rows instead of failing. 116 entries / 144 terms / 18 example pairs from the W-words extract.
- `api/translate.mjs` serverless proxy + `scripts/rag-server.mjs` local proxy (port 3401) + vite `/api` proxy; `npm run dev:full` runs both.
- `scripts/test-retriever.mjs` (`npm run test:rag`) — 16 retrieval assertions, all passing; esbuild-bundles the TS retriever for node.
- Verified end-to-end in headless Chrome with a stub provider: EN→HZ sentence, word lookup, server-key detection. README rewritten with architecture + setup.
- Remaining for the owner: real `.env` (Appwrite + optional `LLM_API_KEY`), and eventually a bigger dictionary — coverage is the real quality lever for a low-resource language.

## MCP server

- Added `src/mcp/server.ts` (MCP stdio server, official `@modelcontextprotocol/sdk@1.17.5`): tools `lookup_word`, `search_dictionary`, `translate_sentence`, `get_lexicon_stats` + resource `dictionary://lexicon`. Bundled to standalone `dist-mcp/mcp-server.mjs` via esbuild (`npm run mcp:build`, run with `npm run mcp`), smoke-tested over real JSON-RPC (`scripts/test-mcp.mjs`, 10 checks).
- Refactor: `translate.ts` split into platform-neutral `translate-core.ts` (no Appwrite/`import.meta.env` — must stay importable from plain Node) + browser facade that wires live Appwrite fusion. Live-block merging moved into the core.
- Extracted `settings-core.ts` (no React) so node bundles don't pull React.
- Gotcha worth remembering: installing `@modelcontextprotocol/sdk@1.32` nested a `zod@4` inside the SDK package and the lockfile kept it after downgrade, which silently broke the SDK's zod3 types (`$ZodType`/`_zod` errors). Purged the nested entries from `package-lock.json` + reinstalled; pinned SDK at exact 1.17.5.
- Also: PWA precache now includes `*.json` (lexicon.json was missing → offline word lookup was broken); added `public/llms.txt` describing the site + lexicon shape; `.mcp.json` at repo root registers the server for MCP clients.
